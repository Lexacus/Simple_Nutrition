# Simple Nutrition

A simple mobile application for tracking calories and macronutrients, built with React, TypeScript and DaisyUI.

## 🌟 Features

- 📱 Mobile-first design
- 📊 Daily tracking of calories and macronutrients
- 🗓️ Weekly meal planning
- 💾 Local data storage with Zustand
- 🔄 Server synchronization (optional)
- 📁 JSON data import/export
- ⚡ Optimized performance with Vite

## 🛠️ Technologies

- React 18
- TypeScript
- Tailwind CSS + DaisyUI
- Zustand (state management)
- Dayjs (date handling)
- React Query
- Capacitor (mobile build)

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/yourusername/simple-nutrition.git
```

2. Install dependencies

```bash
npm install
```

3. Start development mode

```bash
npm run dev
```

4. Build for Android

```bash
npm run android
```

## 📱 Core Features

- **Daily Tracking**
  - Meal logging for breakfast, lunch, dinner, and snacks
  - Automatic calculation of calories and macronutrients
  - Daily progress visualization

- **Weekly Planning**
  - Weekly meal plan creation
  - Copy meals between different days
  - Favorite meals management

- **Data Management**
  - Automatic local saving
  - JSON file backup
  - Optional server synchronization
  - Food database import/export
